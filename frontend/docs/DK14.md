# DK14 — Live workflow & Change Feed (done)

Progress: DK0 ✔ … DK14 ✔ → next DK15 (context widgets: calendar, session clock — OQ-7).

Deviations:
- **OQ-1 default used**: readiness chain = zone entered → lower-TF sweep → lower-TF CHoCH/BOS in the zone's direction → lower-TF FVG in the zone's direction. `buildReadiness` takes any `chain` (subset/order of those four step ids) so DK17 can make it methodology-configured; until then the default is a constant (`DEFAULT_CHAIN`). Steps must occur in order, after the previous step, within 24 h and within 1 ATR of the zone. Each step: pending · seen@time · failed (zone invalidated) · unavailable (direction-less focus), with what is missing.
- **Feed = diff of two folds** (`viewAsOf(objects, ref − 24 h)` vs `viewAsOf(objects, ref)`) through the one as-of path; event time = `known_at`. Meaningful kinds only: entered zone · liquidity swept (new `sweep` object; pool lifecycle "swept" skipped to avoid doubles) · FVG formed · structure break (BOS/CHoCH, "potential change") · invalidated · used up. Swings, impulses, candle signals and round-number levels never appear. Events beyond 3 × ATR of price are dropped unless they touch an accepted (thesis) object. Capped at 40.
- Triage (acknowledge / dismiss / note) is its own local store `spekrym.desk.live.v1`, keyed by event id (includes object id + time), quota-guarded; state-classification row added.
- Thesis panel (inside the Change Feed widget): latest snapshot for pair/day shown unchanged beside "changed since" (events after the snapshot's as-of; thesis objects first). No snapshot ⇒ honest empty state.
- `useBrief` split: `useBriefSession()` (one memoised as-of path for Brief, Feed, Readiness) + `useBrief()` wrapper. Live widgets publish the clicked object to `analysisStore` before selecting, so `E` works.
- `readiness` is now a Live default at Standard+ (registry test updated); Minimal Live = brief + changeFeed + layers.
- Feed list is `aria-live="polite"`; status uses glyph + text; every control is a labelled button.
- Tests: feed kinds/window/relevance/cap/language, no-lookahead on the deep mock (`feed(viewAsOf(full,t)) == feed(detect(prefix t))`), readiness order/failed/unavailable/configurable, thesis, store, widgets.
