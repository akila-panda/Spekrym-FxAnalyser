# DK17 — My Methodology editor & versioning (done)

Progress: DK0 ✔ … DK17 ✔ → **Gate G3** (methodology freeze before the scorecard), then DK18 (Replay & Evidence Timeline).

Deviations:
- **Model**: the active methodology = `DEFAULTS` + a sparse map of overrides (path → value). Effective config = deep copy with overrides applied; `DEFAULTS` is never mutated. No overrides ⇒ exactly `rulesVersion(DEFAULTS)`, so every earlier snapshot/decision/journal entry still matches the defaults version.
- **Editable**: every detector parameter (swing N per TF, ATR/displacement, structure, S/R, reference levels + sessions + DST flag, FVG, liquidity, S/D, price action, TF weights, significance saturations). **Not editable** (presentation, not methodology): `caps` and `relevanceAtr` — rulesVersion stays unchanged by them.
- **Validation**: per-parameter type/range/integer/enum/boolean (inline `role="alert"`), plus cross-rules (S/D base bars min ≤ max; session start < end). Invalid sets are never applied. Enum choices: break rule, FVG fill rule, S/D bounds, detection/base TF (H1/H4).
- **Versioning**: each *Apply* of a new effective config records one version (rulesVersion · name · overrides · time); re-applying an identical config records nothing. History kept (50 max); *Activate* re-applies an earlier version; *Reset to defaults* keeps history. `resolveRulesVersion(rv)` recovers the parameters of any version ever applied (defaults, or the history).
- **Diff vs defaults** is live (staged edits) and lists `path: default → value`; per-parameter *Reset*; *Discard edits*.
- **Plumbing**: Brief, Change Feed/Readiness (via `useBriefSession`), Prepare, the chart pipeline (`useDeskAnnotations`) and the Plan recorder now take the active config and stamp its `rulesVersion`. Presentation constants still read `DEFAULTS` by design. Object ids are unchanged by methodology edits.
- **Unit switch** (pips/ATR) from the design is still deferred: thresholds are ATR, distances are shown in pips elsewhere.
- Editor is the `methodology` widget (Standard+, Analysis dock). No new colours; styles appended to `styles/desk-plan.css`.
- Tests: default-version equality + non-mutation, per-set versions, nested/record/array paths, coverage, validation, cross-rules, cleaning, diff, detection with a changed param (object count + stamped rulesVersion + stable ids), store (dedupe, activate, reset, reject, resolve, persistence, corrupt), editor flow.
- **Gate G3** — owner to freeze the methodology (pick the default/active version) before DK19.
